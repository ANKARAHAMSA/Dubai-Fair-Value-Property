# Independent Skeptical Audit & Remediation Log (`DubaiFairValue`)

Before final release, an independent read-only skeptical audit inspected the full codebase (`src/dfv/`), test suites (`tests/`), committed artifacts (`data/sample/`, `reports/`), CI/container build configs, `.coverage`, and all Phase 7 documentation (`README.md`, `docs/*.md`). Every Critical (`C1–C6`), Medium (`M1–M8`), and Minor (`1–5`) finding was resolved and re-verified on both the full `459,145`-row DLD dataset (`processed`) and the clean-clone `5,000`-row `sample` bundle.

---

## Minor Findings (`1–5`)

1. **Rounding & formatting consistency:** Standardized float precision across `README.md` (`report_render.py`), `docs/model_card.md`, and `docs/interview_notes.md`, and removed nested backtick syntax inside `proj_fe_txt`.
2. **Streamlit UI & caveat polish:** Added predicted `AED/unit` KPI delta & sanitized exception handling on Page 2 (`02_Fair_Value_Checker.py`), added adjacent Route 2020 centroid/post-COVID caveat caption on Page 8 (`08_Events.py`), dropped redundant metric area columns in Imperial mode on Page 9 (`09_Ask_the_Data.py`), and aligned `%` units + sample/processed caption on Page 10 (`10_Model_and_Limits.py`).
3. **Docker vs `requirements.txt` parity:** Updated `Dockerfile` to install locked dependencies directly from `requirements.txt` before `pip install --no-deps .`.
4. **Wide-interval `Low` confidence clarity:** Updated `src/dfv/models/verdict.py` so liquid markets with wide CQR dispersion explicitly note `(Low confidence due to wide 90% uncertainty band relative to median.)`.
5. **Untranslated metro name variants:** Mapped legacy GTFS/HF spellings (`Buj Khalifa Dubai Mall Metro Station`, `Rashidiya Metro Station`, `Damac Properties`, `Union (Green Line )`, etc.) in `data/reference/name_map.csv` and `data/reference/stations_opening.csv`.

## Post-Audit Verification Summary

- **Full Processed Pipeline (`459,145` unflagged DLD sales):** Out-of-time `lightgbm_tuned` **`6.94%` MdAPE** vs `9.50%` best baseline (`baseline_ridge_log`, `+27.00%` relative gain), **`89.93%`** CQR 90% coverage, **`20.22%`** unseen-project spatial hold-out MdAPE (`680` projects), warm FastAPI `/predict` median **`14.67 ms`** (`<= 16.5 ms` across re-runs).
- **Sample CI / Clean-Clone Mode (`DFV_DATA_MODE=sample`):** `ResidualBoostedLGBM` **`6.45%` MdAPE** vs `6.72%` Ridge baseline, **`91.67%`** CQR 90% coverage, **`6.77%`** spatial hold-out MdAPE. An isolated `git archive` clean-clone smoke run additionally caught two test-portability bugs (`tests/unit/test_config.py` asserting `PATHS.root.name == "dubai-fair-value"` instead of structural markers, and `tests/unit/test_models.py` implicitly reading local gitignored `data/cache/`/`data/raw/` on `n=2,200`), both fixed with isolated `tmp_path` directories and `n_sales=5,000`.
- **Verification Gate (`make lint` & `make verify`):** **`83 passed`**, **`89%` code coverage across `src/dfv`**, **`0` skipped checks**, **`Overall Status: PASS`**.
